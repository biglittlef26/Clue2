# Off Campus: Clue Quest 🏒
Three minigames, three clues. Two truths, one lie.

## Run it
Open the folder in VS Code, install the **Live Server** extension, right-click `index.html` → *Open with Live Server*.

## Edit it
- `js/config.js`: intro text, clues, and which clue is the lie
- `js/games/*.js`: each minigame (names, trivia questions, recipe steps)
